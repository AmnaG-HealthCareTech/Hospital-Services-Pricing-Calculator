# Hospital Services Pricing Calculator

## Project Overview
The Hospital Services Pricing Calculator is a Java Swing desktop application designed to calculate the prices of hospital services.

Users can select available medical services, view their prices, calculate the total cost, and add custom services with their own prices.

## Features
- Select hospital services from a dropdown menu.
- Display selected services and their prices.
- Calculate the running total.
- Add custom hospital services.
- Enter custom service names and prices.
- User-friendly graphical interface.

## Technologies Used
- Java
- Java Swing
- ArrayList
- ActionListener
- JFrame, JComboBox, JTextArea, JTextField

## Available Services
| Service | Price |
|---|---:|
| Chest Xray | $25 |
| Blood Test | $10 |
| Urine Dip | $5 |
| Others | Custom price |

## How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the Java file:

```bash
javac HospitalPricingCalculator.java
```

5. Run the application:

```bash
java HospitalPricingCalculator
```
